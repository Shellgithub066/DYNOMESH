# DynoMesh 2026

**Physics & robotics asset exchange** — dynamics packs, URDF, contact models, controllers, and simulation scenes.

## Run locally

```bash
npm install
npm run dev
```

http://localhost:5174

## Deploy

| Step | Action |
|------|--------|
| GitHub | Push this folder as its own repo (see [GITHUB_PUBLISH.md](./GITHUB_PUBLISH.md)) |
| Render | **New → Blueprint** → select repo → `render.yaml` deploys static site |

Details: [DEPLOY_RENDER.md](./DEPLOY_RENDER.md)

## Features

- Membership (Free / Pro / Lab)
- Email or GitHub sign-in
- Publish listings from public GitHub repos
- Multi-step checkout (billing + card + confirm)
- Real per-user likes (no fake counts)
- No public download counters

## Stack

Vite, React 19, React Router, Zustand, localStorage MVP.
